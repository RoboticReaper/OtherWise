## 1. 要实现的体验

用户可以在稳定的完整 Galaxy 上看到已经探索的范围，单击星体查看详情，
双击任意 catalog 星体进入以它为中心的 Focus 视图，再根据真实语义推荐逐步探索。
主题位置和距离有数据依据；队友 demo 的动画用于表达聚焦和点亮过程。

这次合并使用 `BowenX307/otherwise` 的 `8281161` 作为视觉实现参考，选择性迁移
Orb、星空、唤醒、光波、呼吸和镜头过渡。保留来源记录。它当前的固定样例、
三条装饰轨道、8 槽位布局和持续公转不进入产品。

沿用用户选择的星云群岛视觉方向：领域具有颜色与柔和背景层次；不以视觉效果
扭曲已经验证的全局 UMAP＋15% 领域锚点坐标。

## 2. 已确认的行为

| 场景 | 行为 |
| --- | --- |
| Galaxy 单击 | 打开详情，保持 Galaxy 视角，不保存、不解锁、不请求推荐 |
| Galaxy 双击 | 进入以该 topic 为中心的临时 Focus，包括灰色及未保存的星体 |
| 键盘、触屏 | 详情中提供 `Explore from here / 从这里探索`，不依赖双击 |
| 返回 Galaxy | 恢复此前的相机、选中项、搜索和领域筛选 |
| Focus 查看或换中心 | 不修改已保存兴趣、Discover 焦点或兴趣上传许可 |
| 保存兴趣 | 使用现有明确保存流程；Galaxy 点亮该兴趣及其直接近邻 |
| Google / YouTube 搜索 | 记录该 topic 已探索；不保存为兴趣，不点亮它的近邻 |
| 移除兴趣 | 重新计算点亮区域，保留其他兴趣覆盖及真实搜索记录支持的点 |
| 显示位置 | `Map` 内切换 `Galaxy / Focus`；Discover 现有卡片和列表保留 |
| 两种尺寸 | Dashboard 完整体验，扩展侧栏为紧凑版，数据与操作含义一致 |

Focus 表示从一个起点向外探索，不承诺通往指定终点的路线。临时 Focus 与
当前已保存的 Discover focus 是两个状态。保存仍允许现有产品更新其正式焦点，
但不会因此强制改变当前临时 Focus 的中心。

从 Map 的 Focus 标签进入时，优先恢复本窗口上次的临时中心，其次使用当前 Galaxy
选中项，再其次使用可定位的已保存焦点；均不存在时显示主题搜索入口。Focus 内也
可以通过双击或明确按钮换中心，返回 Galaxy 始终回到进入前保存的 Galaxy 视角。

## 3. 全局探索模式

新增独立设置 `galaxyExplorationMode`，默认关闭，提供中英文说明。它只控制呈现，
不改变推荐模式、参数、结果或请求时机。侧栏和 Dashboard 使用现有本地存储同步。

设 `S` 为已保存且可在 catalog 中定位的主题，`N10(s)` 为缓存中该主题在原始
768 维向量空间的 10 个最近邻，`E` 为真实搜索记录中可定位的主题：

```text
兴趣区域 = S ∪ union(N10(s), s ∈ S)
已点亮星体 = 兴趣区域 ∪ E
```

- 只展开一层直接近邻；不会递归扩散，也不会因推荐、悬停、选中而扩散。
- 称为“最近主题 / nearest topics”，不把 top-10 宣称为有统一距离阈值的相近领域。
- 已保存中心有光环，近邻保留领域颜色，单独搜索过的点带探索标记，其余为灰色。
- 推荐可保留轮廓标记；未在点亮集合内时，不能借推荐样式恢复完整彩色区域。
- 选中灰色星体只给临时轮廓及详情。其近邻关系可用细线查看，但不会批量变亮。
- 所有灰色点仍可选择；领域筛选仅调整强调程度，不取消星体命中能力。
- 无已保存兴趣时仍展示完整灰色 Galaxy，可搜索、查看、保存。没有坐标的自定义
  兴趣仍保留在现有列表，不能用虚构位置解锁区域。
- 关闭模式恢复完整彩色图，不删除数据；移除兴趣只去掉它对集合的贡献，不覆盖
  其他兴趣或探索记录。清除数据继续使用现有显式流程。

## 4. Focus 的语义布局

全局坐标完全沿用缓存；Focus 是独立的局部投影。

```text
center = selected catalog topic
d(topic) = acos(clamp(dot(normalized vectors), -1, 1)) / pi
angle(topic) = atan2(global_y(topic)-global_y(center), global_x(topic)-global_x(center))
position(topic) = K * d(topic) * [cos(angle), sin(angle)]
```

`K` 是固定的世界坐标比例，不根据当前推荐批次重新归一化。角度在世界坐标中
求得；屏幕坐标的纵轴翻转交给统一相机变换。重合 UMAP 坐标用中心 ID 与 topic ID
生成确定性角度。极近主题可以共享位置并通过选择列表消歧，不人为修改语义半径。

- 第一次进入就能显示中心与本地缓存的 10 个真实近邻。更多推荐使用接口给出的
  中心距离。围绕中心的参考圈表示语义距离，不表示阅读时长、熟练度或知识等级。
- 同一中心、catalog 和向量版本下，相同 ID 的位置固定。刷新批次、保存、筛选、
  调整窗口或切换语言不能移动已有星体；只影响显隐、标签或相机。
- 领域颜色与 Galaxy 的 23 个领域保持一致；原始 topic 名称和描述不翻译或改写。
- 不保留公转、鼠标吸引、改变坐标的碰撞力或“为填满轨道”而生成的假节点。
- 星体详情可显示中心到该主题的真实距离。明确说明方向来自二维投影，周围星体
  之间的屏幕距离不等于它们之间的真实语义距离。
- 标签碰撞通过隐藏次要标签、悬停显示和列表消歧处理；不通过移动星体解决。

## 5. 推荐与临时焦点的接口边界

保持现有 `/api/recommend` 的已批准关键词规则以及 Discover 的行为。
当前接口要求 focus 属于 keywords，不能通过偷偷加入未保存主题来绕过这一规则。

新增独立、只读的 `POST /api/focus`：

- 输入一个严格匹配的 `topic_id`，catalog hash、embedding hash、模型标识，以及
  现有的 `limit / radius / expansion / overlap / diversity / max_overlap_fraction /
  randomness` 数值参数。没有个人 keywords、历史、URL、页面标题或描述字段。
- schema 严格校验；未知字段、无效 ID、非有限距离参数及版本不匹配均明确失败。
- 以该 ID 对应的现有归一化 catalog 向量为单个种子，复用原推荐器的距离带与
  多样性排名；不新增“目的地”算法，不重新编码主题描述，不用二维位置排名。
- Focus 使用配置中的基础 expansion；不悄悄叠加个人 globalLevel。它与全局自动
  扩大推荐范围是不同能力，原设置继续用于 Discover。
- 返回 schema、独立的推荐算法版本、中心 ID、catalog/model/embedding 身份，以及带 canonical ID 和
  中心距离的推荐记录。记录字段沿用现有推荐结果，文本以本地 catalog 为准。
  当前页面已有的近邻无需再请求，不返回完整距离矩阵或向量。
- 客户端严格核对中心、版本、合法且不重复的 ID（不能是中心）、数量不超过 limit、
  有限且处于 `[0,1]` 和请求距离带内的 distance，以及等于中心的 nearest_interest。
  距离带边界允许 `1e-6` 数值容差。旧的宽松文本清洗函数不能作为此响应的验证器。
  验证失败时不绘制该响应、不将它放入缓存。
- API 与现有服务采用同样的 token、来源限制、请求大小、频率、准备状态、并发
  限制和脱敏错误。现有只保护 `/api/recommend` 的边界必须显式覆盖新路径。
- UI 按稳定 ID 合并近邻和候选，去重并区分“最近主题”和“推荐”。使用现有
  suppressed 集合在本地过滤推荐候选（它包含移除兴趣和两种 dismiss），不能用它
  隐藏临时中心、本地近邻或 Galaxy 星体。显示实际数量，不虚构补足结果。候选有可分页的文本
  列表；图中不靠分页重新排列坐标。

进入 Focus 本身不产生网络请求。旁边的 `Get ideas / 获取推荐` 显示当前中心及
简短说明：“只发送当前主题和推荐参数”。点击才授权本次请求；用户不需要把
主题保存为兴趣。已经开启的兴趣自动更新不自动覆盖这些临时主题。
未配置服务时，本地 10 个近邻仍可用，并提供设置入口。

## 6. 数据、缓存与生命周期

- 持久化：继续保存明确兴趣、搜索记录、推荐设置；只新增探索模式布尔值。
- 每个窗口独立保留：Map 子视图、临时中心、选择、Galaxy 相机快照、Focus 相机、
  动画阶段及请求状态。换临时中心不覆盖 Discover 的 focus、模式或推荐批次。
- Focus 结果使用独立、有上限的内存缓存（最多 20 个请求键）。键包括 endpoint、
  授权配置代次、schema/算法版本、catalog/model/embedding 身份、中心 ID 与参数。
  手动刷新允许重新抽样，但相同 ID 的几何位置不变。
- catalog hash 使用与预处理相同的原始 catalog digest；不能直接给经过打包加工
  的 catalog JSON 做 hash 后拿去比较。embedding hash 使用原始 `.npy` 数组的
  连续字节，并核对其 dtype、shape；服务需在再次归一化之前保留这份身份，不能
  给再次归一化后的 engine.topic_vectors 取 hash 后与原始缓存比较。
- 缓存不能混合不同模型或向量版本；不匹配时保留本地图，提示更新数据，不把不匹配
  响应画成正常结果。原 Galaxy 布局缓存无须重新生成。
- Focus 有独立请求通道和序号；切换中心、返回、关闭视图时使旧响应失效。
  同时打开的侧栏、Dashboard 及 Discover 请求互不取消。更换服务、撤销权限、
  清除数据后，相关旧请求和缓存均失效。
- 保存动作继续走现有控制器。搜索动作显式传递来源：从 Focus 搜索时，轨迹起点
  是临时中心；从 Galaxy 直接搜索时，不虚构连接到旧的 Discover 焦点。轨迹只
  表示实际搜索，不代表保存兴趣或知识掌握。
- 控制器通过可信 catalog 验证临时起点，内部探索事件显式支持这种来源。现有
  EXPLORE 只接受已保存或已探索的 parent，需要适配；不能通过把临时中心偷偷
  加入 approved 或 explored 来获得合法起点。无效来源保持拒绝。
- 复用地图组件的 update/destroy 生命周期，语言或状态更新不反复重播开场。
  卸载、页面隐藏和减少动态效果时清理或暂停不必要的动画循环及监听器。

## 7. 动画与适配

- Dashboard 首次进入 Focus 播放短唤醒；之后切换只做聚焦过渡，不反复播放开场。
- 保存新兴趣时，Galaxy 对新点亮集合播放一次扩散光波。已经亮起的点不重复“解锁”。
- 新推荐出现可用淡入或到达光点表达，不增加探索记录，也不宣称已经解锁。
- 侧栏省略长开场和复杂背景，以短淡入/描边为主。详情使用可滚动的下方区域，
  不遮住主要中心；提供打开 Dashboard 的现有入口。
- 适配产品现有暗色主题和中英文 UI；中文仅为界面支持，推荐内容仍是原始 catalog 文本。
- 系统减少动态效果开启时，停用波纹、脉冲、镜头飞行、视差和缩放动画；运行中
  切换系统偏好也要生效。状态变化通过清晰标记与文字表达。

## 8. 输入、可访问性与异常

- 单击详情与双击进入采用可取消的短单击判定（初始 250ms）。双击在同一星体上
  只触发一次进入；拖动或捏合不触发点击。显式详情/探索按钮不增加这一等待。
- 键盘可以通过搜索结果、列表和详情到达全部主题。Enter/Space 查看详情，显式
  Explore 按钮进入 Focus；Esc 先关闭详情，再返回 Galaxy。恢复合理的键盘焦点。
- 视觉星体大小与命中范围分离；常规目标至少 24px，触屏优先 44px。密集重叠时
  提供确定性候选列表，不让较暗或较小的点永远无法选中。
- 移动端保留可滚动详情和显式缩放按钮，支持平移和双指缩放，正确处理 pointercancel。
- API 不可用、空结果、请求超时、版本冲突和用户撤销权限均有明确状态；本地 Galaxy
  与可用近邻继续工作。Retry 不会保存兴趣，不会应用已过期中心的响应。
- 预览使用公开 catalog 与明确标记的示例个人状态；不接入真实历史，也不把模拟
  推荐或未验证数值伪装为真实后端结果。
