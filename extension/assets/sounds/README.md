The packaged copies retain their original timing, pitch, stereo channels and
48 kHz sample rate. A constant gain matches whole-file RMS levels toward
-25 dBFS, with peaks capped at -3 dBFS. Original files are untouched.
`provenance.json` records source hashes and the gain applied to each copy.

All playback is local. These assets require no external audio service at runtime.
